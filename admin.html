Add a New Product

How to Add a Product:

  1. Fill out the form below with the new product details.
  2. Click the "Generate Product JSON" button.
  3. Copy the entire text that appears in the green-text box below.
  4. Open the products.json file in the code editor.
  5. Add a comma , after the last product's closing brace } and paste the copied JSON code.
  6. Save the products.json file. The new product will now appear on the website.
